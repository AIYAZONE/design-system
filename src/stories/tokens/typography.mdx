# 版式

- 默认字体：**Poppins**
- 日站字体：**Noto Sans JP**

```css
.my-header {
  font: var(--jds-font-display-regular);
}
```


## CSS 变量

下列是设计系统中有关版式的CSS变量

```css

  /* 字体粗细 - 已校准 */
  --jds-font-weight-regular: 400; /* 常规字体 */
  --jds-font-weight-medium: 500; /* 中等字体 */
  --jds-font-weight-semibold: 600; /* 半粗字体 */
  --jds-font-weight-bold: 700; /* 粗字体 */

  /* 字体大小 - 已校准 */
  --jds-font-size-s: 0.75rem; /* 12px */
  --jds-font-size-m: 0.875rem; /* 14px */
  --jds-font-size-l: 1rem; /* 16px */
  --jds-font-size-xl: 1.125rem; /* 18px */
  --jds-font-size-2xl: 1.5rem; /* 24px */
  --jds-font-size-3xl: 2rem; /* 32px */
  --jds-font-size-4xl: 2.5rem; /* 40px */
  --jds-font-size-5xl: 3.5rem; /* 56px */
  --jds-font-size-6xl: 4.5rem; /* 72px */

  /* 非日站字体设置 */
  :root:not([lang="ja"]) {
    /* 字体样式 - 已校准 */
    --jds-font-family: "Poppins", sans-serif; /* 默认字体系列 */
  }

  /* 日站字体设置 */
  :root[lang="ja"] {
    --jds-font-family: "Noto Sans JP", sans-serif; /* 默认字体系列 */
  }
```

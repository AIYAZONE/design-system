富文本小技巧

弹窗内容元素添加 `jds-rte` 类名，保留富文本样式，示例：
  1. 123123
  2. 123123
  3. 123123
  • 123123
  • 123123
  • 123123

本项目LESS文件 变量对应值使用 @vw计算失效

      @base: 750;
      @vw: (1vw / @base) * 100;
      .button {
        --height: 80 * @vw; // Error - 失效
        --height: 10.6667vw; // 生效 80px
        --height: max(0, 80 * @vw); // 生效 80px
        height: 80 * @vw; // 生效 80px
      }

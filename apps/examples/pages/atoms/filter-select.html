Filter Select 下拉筛选多选组件

触发器 + 浮层面板（已选计数 / 清空 / 多选列表 / 确认按钮）。勾选时触发器文案实时更新，确认后才提交到 value

内置多语言

筛选参数、已选择筛选 N 个参数、已选、清空、确定、暂无选项 等文案均取自内置多语言，切换语言即刻生效。

基础用法

各种状态

已选 触发器展示已选数量
自定义已选文案 {label}（{count}）模板
即时生效 关闭底部确认按钮
滚动页面不收起 close-on-scroll="false"（跟随滚动）
含禁用项 禁用项不可勾选
无计数 / 无清空 只保留选项列表与确认
空数据 展示空态占位文案
禁用 整组件不可交互

## 字段来源与映射
- 文档日期：优先取当前文档内现有“最后更新”或 updated 值；若缺失，则使用当天日期
- 标题：取现有 H1 或文件名中的标题
- 文档类型映射：
  - 索引与维护计划 → 索引与维护
  - 技术架构文档 → 技术架构
  - Monorepo架构与工程目录 → 工程目录

  - 组件开发与规范 → 规范与最佳实践
  - 版本与发布-Changesets工作流 → 发布流程
  - 产品需求文档 → PRD
  - 技术分析报告 → 技术分析
  - 项目实现进度分析报告 → 进度报告
  - 项目文档审查报告 → 审查报告
  - 文档编号与格式统一方案 → 文档治理
  - 文档精简与分层维护计划 → 文档维护计划
  - 实现基于Token的CSS变量自动生成（jds-theme.css） → 样式方案
  - 文件驱动主题切换方案 / v1_v2 切换方案 → 主题方案
  - 待办事项 → 工作计划
  - 组件方案（Button/Badge/Checkbox/Dialog） → 组件方案
- 适用范围：统一为“Jackery Design System（JDS）”，组件方案类可加“组件方案”后缀；其余保持通用

# 文件驱动主题切换方案-JDS

## 目标
- 采用“文件驱动”作为唯一主题切换方案：生成 v1 的 `dist/index.css` 与 v2 的 `dist/index-v2.css`

## 技术实现
- 主题入口：`themes/v1/index.less` 与 `themes/v2/index.less` 产出对应版本 CSS
- 构建模式：在 `--mode themes` 中指定两入口并生成 `index.css` 与 `index-v2.css`

## 使用方式
- 引入 v1：页面引入 `index.css`
- 切换到 v2：改为引入 `index-v2.css`

## 组件适配
- 保持组件样式只依赖 CSS 变量；极少数规则级差异按版本覆盖在各自主题入口

## 验证
- 运行主题构建，检查两个产物并在示例页验证切换

## 文档
- 本方案为唯一主题切换方式；不再提供属性方式\n

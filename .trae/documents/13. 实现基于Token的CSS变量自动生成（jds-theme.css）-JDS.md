## 目录规划
- 在 `src/styles/themes/` 下为每个版本建立独立文件夹：
  - `src/styles/themes/v1/index.less`
  - `src/styles/themes/v2/index.less`
- 公共样式与混入保留在公共文件夹：
  - 公共文件：`font.css`、`reset.less`、`public.less`、`rte.less`
  - Token基座与版本：`jds/tokens.base.less`、`jds/tokens.v1.less`、`jds/tokens.v2.less`
- 默认入口：
  - `src/styles/index.less` 默认指向 v1

## 文件关系
- `themes/v1/index.less`：
  - 引用：`../jds/font.css`、`../content/normalize.css`、`../jds/reset.less`、`../jds/public.less`、`../jds/rte.less`、`../animate/index.css`
  - Token：`../jds/tokens.v1.less`
- `themes/v2/index.less`：同上，Token 指向 `../jds/tokens.v2.less`
- `jds/tokens.base.less`：抽取混入与通用定义；版本文件在其基础上输出 :root 变量。

## 构建输出
- 默认样式：`dist/index.css`（来自 `src/styles/index.less`）
- 版本样式：`dist/index.v1.css`、`dist/index.v2.css`
- 变量集自动生成：`dist/jds-theme.v1.css`、`dist/jds-theme.v2.css`（仅 :root 变量）

## 构建配置与脚本
- 新增构建模式 `--mode themes`：
  - 指定输入：`src/styles/index.less`、`src/styles/themes/v1/index.less`、`src/styles/themes/v2/index.less`
- 变量集生成：
  - 编译 `jds/tokens.v1.less`、`jds/tokens.v2.less` → `jds-theme.v*.css`
- 保持库构建（`design:build:lib`/`design:build:single`）现状；主题版本通过 `design:build:themes` 产出。

## 使用指南
- 默认：`import '@jackery/design-system/dist/index.css'`
- 使用 v2：`import '@jackery/design-system/dist/index.v2.css'`
- 仅变量：按需加载 `jds-theme.v2.css` 切换变量

## 验证与风险
- 验证：构建后核对产物与示例页展示
- 风险：差异集中在 Token 层，通过 `tokens.base.less` 降低重复

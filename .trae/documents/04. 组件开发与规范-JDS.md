## 📌 开发总则

* 样式入口：全局样式唯一入口为 `src/styles/index.less`（或通过别名 `@styles/index.less`），由应用入口显式引入。
* 组件样式：以 `index.less?inline` 引入并通过 `unsafeCSS(styles)` 注入到组件 `static styles`，仅使用 `:root` 的 CSS 变量 `var(--jds-...)`。
* 禁止事项：组件内禁止 `@import` 全局样式文件；禁止在组件内定义全局变量或硬编码颜色/尺寸。
* 主题版本：通过文件驱动选择 `dist/index.css`（v1）或 `dist/index-v2.css`（v2）；或通过属性驱动在页面引入 `dist/themes-switch.css` 并设置 `data-jds-theme-version="v2"` 切换。
* 路径别名：在 Vite 配置中添加 `@styles -> src/styles`、`@jackery/* -> packages/*/src`，统一引用路径。

## 🧩 组件目录与模板

* 位置：`packages/core/src/components/<name>/`
* 文件：`index.ts` + `index.less`
* 引入：`import styles from './index.less?inline'`
* 注入：`static styles = unsafeCSS(styles)`
* 变量：使用 `var(--jds-...)`；如需新增变量，在 `src/styles/jds/tokens.less` 定义并由 `src/styles/index.less` 注入。

## ✅ 验证与示例

* 示例站入口：`apps/examples/main.ts`
* 页面验证：`apps/examples/pages/components/index.html` 支持 `?theme=v1|v2` 文件驱动；按钮“切到 v2 / 回到 v1”验证属性驱动。

### 在示例与组件中展示源码（pre/code）

- 为避免被国际化模板插值替换，`initI18nDom` 会跳过 `<pre>/<code>` 容器内文本（`packages/i18n/src/core/dom.ts:12-20`）。
- 在 HTML 页面中直接展示标签源码时，使用转义：`&lt;jds-i18n key="common.ok"&gt;&lt;/jds-i18n&gt;`（`apps/examples/pages/i18n/index.html:28`）。
- 在 Lit 组件模板中展示 `${...}` 字面量时，使用 `&#36;{...}`：例如 `&#36;{t('common.ok')}`、`&#36;{this.title}`（`apps/examples/pages/i18n/i18n-example.ts:30-36`）。
- 推荐在需要展示代码的片段外包裹 `<pre><code>...</code></pre>`，进一步避免非预期处理。

## 1. 总览

* 定位：用于交互确认与信息展示的规范化对话框组件

* 目标：最小 API、主题一致性、专业的可访问性与焦点管理

## 2. 设计目标与原则

* 主题提供“值”（颜色/尺寸/造型/阴影/overlay），组件负责“消费与状态”

* 保持跨主题一致的视觉与行为；减少变量层级与重复覆盖

* API 精简，支持打开/关闭策略与焦点管理

## 3. 组件 API（最小）

* 属性

  * open?: boolean（是否打开）

  * size?: extra | large（默认 large）

  * caption?: string（标题文本，或使用 header 插槽）

  * critical?: boolean（关键对话框，不通过 ESC/遮罩关闭）

  * showClose?: boolean（显示关闭按钮，默认 true）

  * closeOnEsc?: boolean（默认 true）

  * closeOnOverlay?: boolean（默认 true）

  * disableBodyScroll?: boolean（默认 true）

  * initialFocus?: string（初始聚焦选择器）

  * ariaLabel?: string（无标题时的可访问性标签）

* 事件

  * jds-dialog-open / jds-dialog-close（兼容）

  * jds-dialog-request-close（可取消）/ jds-dialog-close（含关闭原因：close-button | keyboard | backdrop | programmatic）

* 插槽

  * header/default/footer（header 可覆盖标题）

## 4. 架构与主题

### 4.1 主题 Tokens

### 4.2 组件消费策略

* overlay + 容器结构；role="dialog"；aria-modal="true"

* 有标题时 aria-labelledby 指向标题ID；否则使用 aria-label

* 焦点管理：打开时保存触发源、设置初始焦点（initialFocus 选择器）；Tab/Shift+Tab 循环；关闭后恢复焦点

* 关闭策略：默认 ESC 与遮罩点击可关闭；critical 优先覆盖，禁用 ESC 与遮罩关闭（如需阻止关闭，监听 jds-dialog-request-close 并阻止默认）

* 滚动锁：打开禁用 body 滚动；关闭恢复

## 5. 样式系统与响应式

* 多主题策略：

  * v1 (Rounded)：使用大圆角（桌面 12px / 移动 24px），柔和阴影。

  * v2 (Straight)：使用直角（0px），锐利风格。

* 响应式布局：

  * Desktop (≥1024px)：

    * large：居中显示，固定最大宽度 (`--jds-dialog-max-width-large`)。

    * extra：居中显示，更宽尺寸 (`--jds-dialog-max-width-extra`)。

  * Mobile (<1024px)：

    * large：居中显示，宽度自适应 (`100vw - padding`)。

    * extra：底部抽屉式进入（Bottom Sheet），宽度 100%，消除底部圆角。

* 动效与无障碍：

  * 移动端 Extra 尺寸使用 `transform: translateY` 实现底部滑入。

  * Reduced Motion：检测到 `prefers-reduced-motion: reduce` 时，强制将动画时长设为 `0.01s`（几乎无动画），确保无障碍体验。

* 强制色模式：

  * 边框/文字兼容 `currentColor`，确保在高对比度模式下可见。

## 9. 使用边界与最佳实践

* Token 优先：新增主题或修改样式时，仅修改 Token 文件，严禁在组件 index.less 中硬编码数值。

* 关键确认场景：使用 critical 属性，防止误触关闭。

* 内容区控制：Header/Footer 使用插槽实现，保持操作区一致性；内容过长时组件会自动处理滚动。

## 10. 命名规范与治理

* Token 前缀：统一使用 `--jds-dialog-*`，语义清晰。

* 消费原则：组件 index.less 只消费 Token，不引入新的局部变量层级，减少维护复杂度。

## 11. 迁移路径 (已完成)

1. Token 化：在 v1/v2 主题文件中补齐 Dialog 的 Tokens（overlay/阴影/半径/宽度/内边距）。
2. 消费改造：组件 index.less 已完全移除固定值，统一消费 Tokens。
3. 验证：Storybook 已包含 ThemeComparison 示例，验证了 v1 (Rounded) 与 v2 (Straight) 的表现。

## 12. 收益与风险

* 收益：统一交互与可访问性；主题治理一致；测试覆盖关键行为

* 风险与缓解：焦点陷阱边界场景（通过测试与回退策略确保可用）

## 13. 推荐选择器策略与示例

* initialFocus 选择器建议：使用语义化 class（如 .confirm-btn/.primary-action）或唯一 id（如 #name-input）；既可匹配插槽内容元素，也可匹配 Shadow 内部元素；找不到选择器时回退到第一个可聚焦元素；无可聚焦元素时回退到容器

* 阻止关闭（jds-dialog-request-close）：

```js
const dialog = document.querySelector('jds-dialog.cancelable')
dialog?.addEventListener('jds-dialog-request-close', (e) => {
  const reason = e.detail?.source // 'close-button' | 'keyboard' | 'backdrop'
  // 业务规则：仅阻止遮罩关闭，其余允许
  if (reason === 'backdrop') e.preventDefault()
})
```

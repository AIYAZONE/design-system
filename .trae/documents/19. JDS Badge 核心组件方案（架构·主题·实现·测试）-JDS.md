# JDS Badge 核心组件方案（架构·主题·实现·测试）
> 最后更新：2026-01-13 · Badge 的架构、主题、实现与测试方案
## 1. 总览

* 定位：用于轻量展示标签或计数，并可作为链接导航
* 目标：最小 API、主题一致性、专业的可访问性与视觉比例

## 2. 设计目标与原则

* 主题提供“值”（颜色/尺寸/造型/比例），组件负责“消费与状态”
* 保持跨主题一致的表现；减少变量层级与冗余映射
* 聚焦展示与导航，移除不必要交互（关闭/点击）能力

## 3. 组件 API（最小）

* 属性
  * size: small | medium | large（默认 medium）
  * variant: soft | solid | outline（默认 soft）
  * kind: default | neutral | success | warning | danger | info | custom（默认 default）
  * icon?: 图标名称（统一前置）
  * count?: number（计数优先生效）
  * maxCount?: number（默认 99；超过显示“99+”）
  * href?: string（渲染为 a，rel="noopener noreferrer"）
* 插槽
  * 默认插槽：文本
  * icon 插槽：覆盖 icon 属性（统一前置）
* 高级配置（建议在主题或页面样式中）
  * --jds-badge-custom-color（自定义主色，仅 kind=custom）
  * --jds-badge-soft-mix（custom+soft 背景浅化比例，默认 65%）
  * --jds-badge-soft-fg-darken（custom+soft 前景加深比例，默认 20%）

## 4. 架构与主题

### 4.1 主题 Tokens

* 颜色与语义
  * --jds-badge-bg-color、--jds-badge-color
  * soft：--jds-badge-soft-bg、--jds-badge-soft-fg
  * solid：--jds-badge-solid-bg、--jds-badge-solid-fg
  * outline：--jds-badge-outline-border、--jds-badge-outline-fg
* 自定义与调优
  * --jds-badge-custom-color（主色）
  * --jds-badge-soft-mix（白色混合比例）
  * --jds-badge-soft-fg-darken（前景加深比例）
* 造型与尺寸
  * --jds-badge-border-radius（v1 Pill、v2 直角）
  * s/m/l：height、padding-x、font、icon-size、gap

### 4.2 组件消费策略

* 统一前置图标，尺寸与比例由主题驱动（纵向 height，横向 padding）
* 计数优先生效（count > maxCount → “maxCount+”）
* href 存在时渲染为 a.badge（设置安全 rel）

## 5. 样式系统

### 5.1 变体

* soft：浅色背景 + 主色前景（neutral/custom 场景提供专用 soft 颜色）
* solid：主色背景 + 白色前景（可覆盖）
* outline：透明背景 + 主色描边 + 主色前景

### 5.2 语义（kind）

* default/neutral/success/warning/danger/info/custom
* custom + soft：支持 soft-mix 与 soft-fg-darken 参数化调优

### 5.3 尺寸与造型

* small/medium/large：高度驱动纵向居中，横向 padding 控制
* 图标尺寸与间距：12/14/16 与 gap=4 的统一比例
* 造型由主题控制（v1 Pill、v2 直角）

### 5.4 状态与可访问性

* 导航：href → a.badge，rel="noopener noreferrer"
* 仅计数且无文本：自动生成 aria-label（如“计数：99+”）
* 强制色：outline 使用 currentColor（高对比）

## 9. 使用边界与最佳实践

* Badge 专注展示与导航，不承担关闭/点击等交互
* 可点击/可关闭标签场景建议使用 Chip/Tag
* 自定义品牌色优先在主题设置；页面按需覆盖 --jds-badge-custom-color

## 10. 命名规范与治理

* Token 前缀统一（--jds-badge-*），语义清晰
* 新主题或状态变更仅改 Tokens；组件避免新增局部变量层

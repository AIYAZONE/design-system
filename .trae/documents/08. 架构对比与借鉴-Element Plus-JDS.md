# 架构对比与借鉴：Element Plus ↔ Jackery Design System (JDS)

## 1. 概述
- 目标：系统性对比 Element Plus 与 JDS 的架构与能力，制定可操作的对齐与迁移方案。
- 方法：从组件模型、主题系统、API 语义、构建与发布、文档与示例、可访问性六大维度进行评估与借鉴。

## 2. 架构对比
- 组件模型：Element Plus 基于 Vue；JDS 基于 Web Components + Lit，框架无关、可跨生态复用。
- 状态与渲染：Element 通过响应式数据与模板；JDS 通过 Lit 的声明式模板与属性反射。
- 互操作性：Element 在 Vue 生态内最佳；JDS 原生 DOM 组件，在 React/Vue/Svelte/原生均可用。

### 构建输出形态对比（汇总包 vs 按需）
- Element Plus：同时提供全量汇总与按需引入方案，利于多场景消费。
- JDS：提供两类构建模式以对齐能力，主题切换采用文件驱动（index.css/index-v2.css）：
  - 多文件库（按需拆分）：`pnpm run design:build:lib`，入口更小、图标与资源按需加载；适合应用打包场景
  - 单文件库（完全聚合）：`pnpm run design:build:single`，部署简单但首屏体积较大；适合 CDN/脚本标签直接引入

## 3. 组件覆盖与映射
- P0：Button、Input、Select、Checkbox、Radio、Switch、Dialog、Tooltip、Message、Notification。
- P1：Pagination、Breadcrumb、Tabs、Tag、Progress、Card、Collapse、Descriptions、Avatar、Empty。
- P2：Table、Tree、DatePicker、TimePicker、Cascader。

示例映射表（节选）：
- `ElButton` ↔ `jds-button`
- `ElDialog` ↔ `jds-dialog`
- `ElInput` ↔ `jds-input`

## 4. API 与事件对齐
- 属性：`type|variant`、`size`、`disabled`、`loading`、`plain`、`round`、`circle`、`icon`、`text`。
- 事件：`click`、`input`、`change`、`focus`、`blur`，对齐命名与行为；保留原生 DOM 冒泡。
- 插槽：`prefix`、`suffix`、`default`，通过 `<slot>` 承载。

## 5. 主题变量映射
- 颜色：`--el-color-primary` ↔ `--jds-color-primary`
- 文本色：`--el-text-color-primary` ↔ `--jds-text-primary`
- 尺寸：`--el-component-size-small` ↔ `--jds-size-sm`
- 圆角：`--el-border-radius-base` ↔ `--jds-radius-md`
- 阴影：`--el-box-shadow` ↔ `--jds-shadow-md`

示例脚本片段：
```ts
// scripts/map-el-to-jds.ts
type Mapping = { el: string; jds: string };
export const colorMappings: Mapping[] = [
  { el: '--el-color-primary', jds: '--jds-color-primary' },
  { el: '--el-text-color-primary', jds: '--jds-text-primary' }
];
```

## 6. 文档与示例对齐
- 文档模板：概述 → 示例 → 属性 → 事件 → 插槽 → 样式变量 → 无障碍 → FAQ。
- 示例维度：基础、状态、尺寸、图标、组合、国际化；与 Element Plus 对齐。
- Storybook 交互：使用 `play` 与 a11y 插件进行自动化交互与可访问性检查。

## 7. 迁移策略
- 渐进式：按照页面区域优先迁移高频组件（Button/Input/Dialog 等）。
- 包装层（可选）：提供 Vue 适配包装以统一插槽与事件命名差异。
- 自动化：属性/事件/变量映射替换脚本、文档对照与校验工具。

## 8. 风险与缓解
- 复杂组件行为差异（Table/Tree）：先保障核心功能，逐步补齐高级特性；提供替代方案与限速发布。
- 主题变量不等价：提供扩展与覆盖策略；允许项目级定制。
- 团队使用习惯差异：培训、示例库、迁移清单。

## 9. 成功指标
- 组件与文档对齐度 ≥ 85%；示例覆盖 ≥ 90%。
- 至少 3 个项目完成部分组件迁移并稳定运行。
- 迁移脚本覆盖 ≥ 80% 常见属性/事件/变量。

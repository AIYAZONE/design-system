## 📌 规范摘要

* 全局样式唯一来源为 `src/styles/index.less`，在应用入口显式引入。

* 组件样式以内联方式注入（`index.less?inline`），仅依赖 `:root` 的 CSS 变量。

* 核心包不再自动注入全局样式；删除重复来源（`packages/core/src/styles/index.css`、`internal.less`）。

* 在 Vite 中添加 `@styles -> src/styles` 别名，统一引用与入口加载。

***

## 🎯 使用原则

* 全局：统一由 `src/styles` 管理字体、设计令牌、重置、公共样式与动效。

* 组件：仅在组件内注入结构样式，主题与尺寸全部来源于 `:root` 的 CSS 变量。

* 禁止：在组件内 `@import` 全局样式文件；在组件内定义全局变量或硬编码色值/尺寸。

***

## 🧩 全局样式入口

* 示例站入口：`apps/examples/main.ts:3`

  * `import '../../src/styles/index.less';`

* 推荐使用路径别名：

  * `import '@styles/index.less';`

### 构建产物与消费

* 库构建（汇总包）：产出 `dist/index.css`，作为设计系统样式总入口，包含字体、令牌、重置、公共样式与动效。

* 单文件库构建：产出 `dist/index.single.css`，用于 CDN/脚本标签直接引入的场景。

***

## 🧱 组件样式模型

* 组件代码：通过 `index.less?inline` 引入并用 `unsafeCSS(styles)` 注入到 `static styles`。

  * 示例：`packages/core/src/components/dialog/index.ts:5` 引入；`packages/core/src/components/dialog/index.ts:20` 注入

* 变量使用：统一使用 `var(--jds-...)`（来源于 `src/styles/jds/tokens.less` 注入的 `:root`）。

* 按需示例：

  * 颜色：`var(--jds-color-primary)`、`var(--jds-color-success)`

  * 尺寸：`var(--jds-size-16)`、`var(--jds-rounded-12)`

  * 字体：`var(--jds-font-b1-medium)`、`var(--jds-font-h4-medium)`

***

## 🧭 Vite 别名与入口规范

* 根站点 `vite.config.js:127-140` 与示例站 `apps/examples/vite.config.js:24-35` 已配置：

```
resolve: {
  alias: {
    '@': <src>,
    '@styles': <src/styles>,
    '@jackery/core': <packages/core/src>,
    '@jackery/icons': <packages/icons/src>,
    '@jackery/i18n': <packages/i18n/src>,
    '@jackery/utils': <packages/utils/src>,
  }
}
```

* 入口示例：

```
import '@styles/index.less';
import '@jackery/core';
import '@jackery/icons';
```

***

## 🔧 核心包样式策略调整

* 入口不再注入全局样式：`packages/core/src/index.ts:17` 已删除 `import './styles/index.css'`。

* 删除重复样式来源：

  * `packages/core/src/styles/index.css`（全局变量与重置）

  * `packages/core/src/styles/internal.less`（内部令牌与混合器）

* 组件仅依赖 `:root` 变量；如需混合器，请在组件内本地定义且不产生全局作用。

***

## 🛠 组件开发指引

* 位置：`packages/core/src/components/<name>/`

* 文件：`index.ts` + `index.less`

* 引入：`import styles from './index.less?inline'`

* 注入：`static styles = unsafeCSS(styles)`

* 变量：仅使用 `var(--jds-...)`；如需新增变量，在 `src/styles/jds/tokens.less` 定义并由 `src/styles/index.less` 注入。

***

## 🔁 迁移要点（从旧结构）

* 移除核心包样式目录内的全局样式与内部令牌文件：`index.css`、`internal.less`。

* 将项目统一指向并在入口引入 `src/styles/index.less`（或 `@styles/index.less`）。

* 检查组件样式，移除对内部令牌的依赖，改为 `var(--jds-...)`。

* 在 Vite 中添加 `@styles` 别名，统一入口引入与引用路径。

***

## ✅ 验证方法

* 启动示例站：`pnpm -w --filter @jackery/examples dev`（端口示例：`http://localhost:5175/`）

* 页面验证：

  * `http://localhost:5175/pages/atoms/button.html`

  * `http://localhost:5175/pages/atoms/dialog.html`

* 检查：变量是否来自 `src/styles/jds/tokens.less`；组件是否只依赖变量且表现正确；不存在来自核心包的重复变量注入。

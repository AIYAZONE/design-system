## 目标
- 默认采用文件驱动：继续生成 v1 的 `dist/index.css` 与 v2 的 `dist/index-v2.css`
- 同时提供属性驱动：在 `html`/`body` 上加 `data-jds-theme-version="v2"` 即切到 v2；产出一个 `dist/themes-switch.css` 可与默认样式共同使用

## 技术实现
- 重构主题 tokens（v1/v2）：将硬编码的 `:root` 改为可参数化的选择器变量（如 `@rootSel`），媒体查询内的 `:root` 一并替换
- 主题入口：
  - v1/v2 入口继续设置 `@rootSel: :root`（文件驱动产物不变）
  - 新增 `src/styles/themes/switch.less`，设置 `@rootSel: :root[data-jds-theme-version="v2"]` 并引入 v2 tokens → 覆盖变量仅在设置属性时生效
- 构建：在 `--mode themes` 构建中新增输入 `themes/switch.less`，输出 `dist/themes-switch.css`

## 使用方式
- 文件驱动（默认）：页面引入 `index.css`（v1）；需要 v2 时改引 `index-v2.css`
- 属性驱动（运行时切换）：页面引入 `index.css` + `themes-switch.css`，通过 `document.documentElement.dataset.jdsThemeVersion = 'v2'` 切换

## 组件适配
- 保持组件样式只依赖 CSS 变量（已完成）；如需极少数规则级差异，在 `themes/v1|v2` 下新增组件局部覆盖文件并在对应入口引入

## 验证
- 运行主题构建，检查 `index.css`、`index-v2.css`、`themes-switch.css` 三个产物
- 示例页添加/移除 `data-jds-theme-version` 验证运行时切换

## 如何使用文档

从左侧目录选择组件。文档页提供用法和可操作的示例，组件预览页可以调整参数，查看不同状态。

组件演示保留设计系统的真实主题，文档外框可在顶部导航切换深色或浅色，并记住选择。页面中的颜色、字号和间距说明在“设计变量”目录里。

## 安装到项目

```sh
pnpm add @aiyazone/design-system
```

需要让 AI 阅读组件说明时，从 [llms.txt](/llms.txt) 开始。生成页面后，检查内容、按钮、表单与手机布局。

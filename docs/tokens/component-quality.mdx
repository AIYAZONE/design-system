# 组件质量与组合规则

本规范约束组件组合与示例文档。V1、V2、V3 仍是独立主题，默认主题不变；不以统一文档排版覆盖真实组件样式。

## 视觉与密度

同一操作组使用相同用途的密度。品牌主操作、常规表单、紧凑筛选可以采用不同高度；不能只因为它们都是控件，就将全部尺寸强行相同。

| 决策 | 规则 |
| --- | --- |
| 排版 | 文档使用门户字体；真实组件、字体与富文本样张使用对应主题字体。 |
| 点击区域 | 复选框方框与点击区域分别处理，方框保持原尺寸，整行标签提供至少 44px 的默认高度。 |
| 操作层级 | 真实任务中主次明确；组件状态矩阵允许同时展示多个主按钮。 |
| 焦点 | `--zone-focus-color` 提供跨组件定制入口；组件专用焦点变量优先。未覆盖时保留原主题默认值。 |
| 状态 | 选中、焦点、禁用、加载分别表达；不为静态组件增加无意义的交互状态。 |
| 动效 | Button、Dialog、Filter-select、Spinner 尊重减少动效设置；等待仍需文字或可访问说明。 |
| 浮层 | 复用 Floating UI；打开后启动定位，关闭和卸载时释放。Escape 优先处理当前内层浮层。 |

响应式尺寸必须记录浏览器实际渲染值。`--zone-size-*` 在不同主题和根字号下不能直接视为同名的 CSS 像素数。

## 每类组件的完成条件

| 组件 | 必验行为 |
| --- | --- |
| Button | 点击与键盘单次激活；链接语义；submit/reset；禁用与加载名称。 |
| Checkbox | 原生 FormData、reset、fieldset 禁用、Space 与可见焦点。 |
| Badge | 静态信息与导航分开；计数业务名称、页面语言与图标尺寸。 |
| Dropdown | 表单、叶子选择、活动项与选中分离、虚拟列表与嵌套 Escape。 |
| Filter-select | 草稿、确认、取消、即时模式、外部 open/disabled 与监听释放。 |
| Dialog | 背景隔离、初始焦点、循环与返回；单次关闭事件；标题、页脚与关闭名称。 |
| Popover | 元素或 ID 目标、重新绑定、内部点击、边缘避让与卸载清理。 |
| Tooltip | 说明关联到真实焦点控件；Escape、指针连续性与触摸不吞主操作。 |
| Toast | 超时停止、重开、暂停；不删除操作插槽内容；状态播报与关闭。 |
| Spinner | 装饰与独立等待分别命名；减少动效；遮罩只是忙碌提示，不构成模态隔离。 |

Spinner 默认作为装饰。独立区域通过 `label` 提供名称，并由调用方管理内容区的 `aria-busy`。Badge 的 `aria-label-text` 用于“3 条未读消息”等业务名称。

## 表单与属性兼容

Checkbox 通过表单关联自定义元素接入原生表单。未提供 ElementInternals 表单接口的浏览器，需要业务代码收集其值；不会自动伪造隐藏字段。

Button 与 Badge 的 `icon-position`、Badge 的 `max-count`、Dialog 的多词属性、Toast 的 `countdown-time` 使用显式 HTML 属性名。已有不带连字符的旧拼写仍作为兼容入口；新代码使用标准拼写；为兼容旧项目，运行时更新旧拼写也继续生效，避免在同一元素混用两种拼写。

Button 设置 `href` 后采用原生链接语义；Space 不模拟按钮点击。Dialog 的 `caption` 按纯文本显示，富文本标题通过 `header` 插槽提供。`zone-dialog-close` 每次关闭只触发一次，detail 包含 `isOpen: false` 与 `reason`。

## 示例页与验证

全部 Examples 共用导航、主题工具栏、章节画布与目录，完整状态默认展开。方向演示使用网格，通知使用纵向列表，字体与富文本保留样张，翻译表格局部滚动。原有路由和 Dropdown 的 pc/mb 预览参数保留。

`node scripts/check-examples-browser.mjs` 检查当前源码页面在三主题、1440/768/390/320px 下的加载、目录与溢出，并验证代表性交互。需要先构建 Examples；结果和截图写入 `output/examples-20261119`。`EXAMPLES_ORIGIN` 可指定一个正在运行的示例站。

组件单元测试、浏览器交互与自动无障碍扫描分别提供证据，不能互相替代。真实读屏、真机触摸以及实际业务复用收益仍需人工评审；没有这些证据时不宣称已全面达到无障碍或业务成熟标准。

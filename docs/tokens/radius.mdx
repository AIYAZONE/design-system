# 圆角 - Size and Spacing

## 概述

圆角系统是我们设计系统中的重要组成部分，用于统一和规范化界面元素的圆角效果。我们的圆角系统基于以下原则设计：

### 基础圆角
- 2px：适用于组件长度小于20px的组件
- 4px：适用于组件长度20-60px的组件
- 8px：适用于组件长度大于60px的组件

### 卡片圆角
- PC端：12px
- 移动端：24px

### 嵌套圆角
- 内卡片：14px
- 外卡片：24px

### 特殊圆角
- 胶囊圆角(999px)：用于标签、徽章等需要完全圆润效果的元素
- 圆形(50%)：适用于头像、图标按钮等需要完全圆形的元素

## CSS 变量

```css
/* ========================================
 * 边框圆角系统 (Border Radius System)
 * ======================================== */
.generate-border-radius(@rem-base) {
  --jds-border-radius-2: max(0, 2 * @rem-base);                /* 当需要使用圆角的组件长度小于20px时，使用2px圆角 */
  --jds-border-radius-4: max(0, 4 * @rem-base);                /* 当需要使用圆角的组件长度在20-60px时，使用4px圆角 */
  --jds-border-radius-8: max(0, 8 * @rem-base);                /* 当需要使用圆角的组件长度大于60px时，使用8px圆角 */
  --jds-border-radius-12: max(0, 12 * @rem-base);              /* PC端卡片圆角 */
  --jds-border-radius-14: max(0, 14 * @rem-base);              /* 嵌套圆角-内卡片圆角*/
  --jds-border-radius-24: max(0, 24 * @rem-base);              /* 移动端卡片圆角、嵌套圆角-外卡片圆角*/
  --jds-border-radius-pill: 999px;                             /* 胶囊圆角：标签、徽章 */
  --jds-border-radius-circle: 50%;                             /* 圆形：头像、图标按钮 */
}

@media screen and (min-width: 1024px) {
  @rem: (1rem / 16);
  :root {
    /* 生成桌面端边框圆角变量 */
    .generate-border-radius(@rem);
  }
}

@media screen and (max-width: 1023.98px) {
  @rem: (1rem / 32);
  :root {
    /* 生成移动端边框圆角变量 */
    .generate-border-radius(@rem);
  }
}
```

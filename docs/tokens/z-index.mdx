# 层级 - Z-index

## 概述
Z-index 层级系统是用于控制元素在页面中的堆叠顺序的重要机制。我们的层级系统采用了清晰的分层设计，从深层级（-1）到通知层级（600），每个层级都有其特定的使用场景和目的。

这种系统化的设计确保了不同类型的界面元素能够按照预期的方式显示和交互，避免了层级混乱导致的视觉和功能问题。例如，对话框总是会显示在普通内容之上，而通知消息则会显示在最顶层。

在使用这些层级变量时，建议遵循以下原则：
- 1.优先使用预定义的层级变量，而不是直接使用数值
- 2.根据元素的功能和重要性选择合适的层级
- 3.避免在同一层级范围内自定义中间值，以维持系统的一致性

> 以下变量表由 `packages/tokens/tokens.json` 自动生成（`pnpm docs:gen`），请勿手改。

--zone-index-deep: -1; /* 深层级：负层级，用于背景元素 */

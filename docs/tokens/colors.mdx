# 变量

## 概述

色彩是设计系统中最基础的视觉元素之一，在 AIYAZONE Design System 中，我们建立了一套完整的色彩系统。这套系统包含了：

- **功能色**：包括主色（品牌橙）、成功色、错误色、警告色和信息色，用于传达不同的状态和信息。
- **文本色**：包括不同层级的文本颜色和状态文本颜色，确保内容的可读性和层次感。
- **其他色彩**：包括图标颜色、背景色、卡片色、线条颜色等，用于构建完整的界面视觉层次。

我们的色彩系统遵循以下原则：
- 1.保持品牌一致性
- 2.确保足够的对比度，提升可访问性
- 3.建立清晰的视觉层次
- 4.传达准确的信息状态

说明：当前仅提供浅色主题配色方案。

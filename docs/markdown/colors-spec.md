# 规范

- V1主题，用于官网4.0设计。
- V2主题，用于官网5.0设计。
- V3主题，用于官网5.0设计（欧洲版）。

说明：表格中括号里的 “90%/60%/40%/30% …” 为设计备注，不代表需要在前面的色值上再叠加透明度；前面的色值即为最终实现色值。

这个设计方案以 **#FD5000**（鲜艳橙色）作为核心品牌色，搭配深绿灰调的文字主色 **#242F20**，整体风格偏自然、现代、环保感（绿色成功色 #5E8A4E 也强化了这一点）。深色模式主背景为深绿灰 #242F20，保持一致性。

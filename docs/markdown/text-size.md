### V2 在设计系统中的落地说明

- 设计系统对外提供：`.zone-h1`~`.zone-h6`、`.zone-b1`~`.zone-b3`、`.zone-c1`，命名保持与 V1 一致。
- V2 表格中的 Display/H0/H1... 等设计稿命名，会按“对应原字体系统”列映射到上述 H/B 命名（例如 Display 2 → H1，H0 → H2）。
- 额外提供快速配置类：`.zone-display-1` / `.zone-display-2` / `.zone-display-3`。
- 如需任意字号/行高/字重/色值/字间距组合，使用 `.zone-custom-font` 并通过 CSS 变量自定义。
- 移动端设计基于 375 标注；代码 tokens 采用 750 输出，因此实现时移动端字号等数值会 ×2。

# 响应式设计文档

## 概述

本文档详细说明了 Jackery 设计系统中响应式设计的实现方案，基于 CSS `clamp()` 函数实现跨设备的大小自适应。

## 代码实现

```css
/* 文件位置：src/styles/content/normalize.css */

/* PC端 */
@media screen and (min-width: 1024px) {
  html {
    /* 使用clamp()函数设置字体大小:
     * 最小值: 12px
     * 首选值: 1.111111vw (视窗宽度的1.111111%)
     * 最大值: 16px
     */
    font-size: clamp(12px, 1.111111vw, 16px);
  }
}

/* 移动端（<1024px） */
@media screen and (max-width: 1023.98px) {
  html {
    /* 使用clamp()函数设置字体大小:
     * 最小值: 16px
     * 首选值: 4.266666vw (视窗宽度的4.266666%)
     * 最大值: 32px
     */
    font-size: clamp(16px, 4.266666vw, 32px);
  }
}
```

## 技术原理

### `clamp()` 函数语法

```css
clamp(最小值, 首选值, 最大值)
```

- **最小值**: 字体大小的下限
- **首选值**: 基于视口宽度的动态值
- **最大值**: 字体大小的上限

### 视口单位 (vw)

- `1vw` = 视口宽度的 1%
- `4.266666vw` = 视口宽度的 4.266666%
- `1.1111vw` = 视口宽度的 1.1111%

## 设备适配策略

### PC端 (≥1024px)

| 视口宽度 | 计算公式 | 字体大小 | 说明 |
|---------|---------|---------|------|
| ≤ 1080px | 12px (最小值) | 12px | 防止字体过小 |
| 1080px - 1440px | 1.1111vw | 动态缩放 | 流体字体 |
| ≥ 1440px | 16px (最大值) | 16px | 防止字体过大 |

**临界点计算:**

- 最小值触发: `12px ÷ 1.1111% = 1080px`
- 最大值触发: `16px ÷ 1.1111% = 1440px`

### 移动端 (<1024px)

| 视口宽度 | 计算公式 | 字体大小 | 说明 |
|---------|---------|---------|------|
| ≤ 375px | 16px (最小值) | 16px | 保证可读性 |
| 375px - 750px | 4.266666vw | 动态缩放 | 流体字体 |
| ≥ 750px | 32px (最大值) | 32px | 适合触屏操作 |

**临界点计算:**

- 最小值触发: `16px ÷ 4.266666% = 375px`
- 最大值触发: `32px ÷ 4.266666% = 750px`

## 设计理念

### 1. 可访问性优先

- **移动端最小16px**: 确保在小屏设备上的可读性
- **PC端最小12px**: 在大屏幕上保持紧凑布局

### 2. 触屏友好

- **移动端最大32px**: 适合手指触控操作
- **更大的字体比例**: 移动端字体范围 16px-32px vs PC端 12px-16px

### 3. 流体设计

- **连续缩放**: 在临界点之间平滑过渡
- **比例一致**: 保持视觉层次的相对关系

## 维护指南

### 修改范围

1. **调整最小值**: 考虑可访问性标准
2. **调整最大值**: 避免字体过大影响布局
3. **重新计算vw值**: 确保在目标断点处达到期望大小

### 计算公式

``` html
vw值 = (目标大小 / 视口宽度) × 100
```

**示例**: 在750px宽度下显示32px

```html
vw值 = (32 / 750) × 100 = 4.266666vw
```

## 总结

这套响应式字体系统通过 `clamp()` 函数实现了:

- ✅ **跨设备一致性**: PC和移动端都有合适的字体大小
- ✅ **流体缩放**: 平滑的字体大小过渡
- ✅ **可访问性**: 保证最小可读字体大小
- ✅ **性能优化**: 纯CSS实现，无需JavaScript
- ✅ **维护简单**: 集中管理，易于调整

通过这种方式，Jackery 设计系统确保了在所有设备上都能提供优秀的阅读体验。

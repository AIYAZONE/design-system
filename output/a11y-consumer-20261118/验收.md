# ZDS-05/06 无障碍与消费者浏览器验收

日期：2026-11-18。范围：ROADMAP 批次 3；公开版本仍为总包 0.4.1、tokens 0.1.1，本批通过 Changeset 准备下次 minor 版本。

## 问题与修复

首次 Chromium 报告覆盖 79 个 stories，其中 56 个有违规：54 个报告 `color-contrast`，两个报告 `button-name`，两个报告 `label-content-name-mismatch`。部分 story 同时触发多种规则。原始节点、颜色、对比度与规则信息见 [修复前报告](storybook-before.json)；button、badge、dialog 的失败断言见 [回归失败日志](regression-before.log)。

- 加载按钮保留可访问名称并暴露忙碌状态；恢复键盘焦点轮廓，原生按钮单次 Enter 只派发一次点击。
- 弹窗关闭图标改为有名称的原生按钮，标题语义改为二级标题；焦点遍历包含插槽及 Shadow DOM，跳过隐藏和禁用控件，无可用控件时聚焦容器，关闭后恢复触发控件的内部焦点。
- 实际生产页面发现打开过渡时输入框仍为 `visibility: hidden`，初始聚焦被浏览器忽略。打开时立即可见、保留透明度动画。证据见 [焦点失败状态](dialog-focus-before.json) 与 [截图](dialog-focus-before.png)。
- 下拉树节点使用明确的文字标签和子组所有权；长列表增加可聚焦的树／列表入口，并同步活动节点。中途三尺寸报告仅剩一个手机滚动区域违规，见 [中途报告](storybook-intermediate.json)。
- 调整 tokens 真源中的语义色及悬浮色、V1 辅助文字与 Toast 文字；同步生成文件和手写编译基线。自定义 story 的图标按钮补名称，自定义颜色补足对比度。

## 浏览器检查

消费者由本仓库 tarball 独立安装后进行 Vite 生产构建，无源码别名。公开项目只安装总包与 tokens；内部项目继续检查基础包、总包及两种混用顺序。覆盖 1440 / 768 / 390 三尺寸，每组检查三主题。

检查按钮点击／Enter 单次事件、键盘焦点轮廓、共享 Lit、动态图标、英语切日语、加载名称、弹窗初始焦点／Tab／Shift+Tab／关闭 Enter／Escape／焦点恢复、所有控件禁用时的焦点保留、树下拉键盘选择与真实事件、主题覆盖、打开弹窗及关闭页面的 axe 结果和浏览器错误。扫描等待弹窗动画结束，避免过渡期间颜色造成不稳定结果。

公开三组与内部十二组全部通过，浏览器错误为零。结果见 [公开消费者](public-browser-results.json)、[六包消费者](internal-browser-results.json)，截图见 [桌面](bundle-1440.png)、[平板](bundle-768.png)、[手机](bundle-390.png)；调整后的默认主题见 [按钮截图](buttons-1440.png)。

最终源码的 79 个 Storybook 渲染检查通过；三尺寸共 237 次 axe 扫描违规为零，见 [完整报告](storybook-after.json)。其中 87 次扫描保留 `incomplete`，涉及跨 Shadow DOM 的 ARIA 引用／属性与少量对比度、名称判断，供人工继续核查，未将其当作完整认证。远端同一提交 CI 验收完成后补充交付链接。

## 清理与检查边界

真实失败退出已验证诊断 JSON 和截图生成、安装目录清理；HTTP 回调故意抛错后端口不可访问，后续服务能正常启动。默认 `finally` 清理消费者、浏览器和服务，`--keep` 仅供人工诊断。CI 失败上传消费者及 Storybook 诊断文件，required check 保持 `Build · Type · Test · Tokens · Docs`。

完整测试 296 项通过（core 176、icons 118、i18n 1、utils 1），类型与 lint 通过；令牌三主题手写基线验证、发布范围检查、AI 样例检查及文档生成稳定性通过。日志见 [测试](tests.log)、[令牌基线](token-baseline.log)。

jsdom 检查语义结构，实际布局和对比度由 Chromium 检查。Storybook 沿用已有 addon 扫描范围，仅保留文档画布已有的 `region` 关闭设置。报告保留 `incomplete` 供人工判断。Chromatic 上传成功仅表示上传完成，不能代替视觉差异审批；当前自动结果不代表完整无障碍认证。

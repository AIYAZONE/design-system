# 数字商业平台架构全景验收

日期：2026-11-17。范围：ZDS 门户页面与静态蓝图。开发入口 `http://localhost:5173/architecture.html`，生产产物使用本机临时 Vite preview 验证；未发布到外部。

## 交付

- 七层 39 模块 + 四项横切治理，共 43 模块、217 子能力、92 关系；图、详情、功能清单、状态与六场景使用一个数据源。
- 五视图：分层全景、依赖与调用、数据归属、区域部署、设计与验证。
- 六类业务应用按使用人群和任务分类；站点、页面类型、渠道、组织品牌与区域配置分开解释。
- 模块详情包含职责、子能力、上下游、输入输出与失败契约、数据权威、部署与故障边界、状态与证据。
- Atlas 源码现状与目标区分：会员/工单/营销规则、区域隔离、Outbox/异步发布、AWS 运行与恢复均未冒充已部署。
- 历史完整图、评分与自评资料在页面末尾折叠保留，标明历史与未重新核实。

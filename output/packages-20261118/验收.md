# ZDS-01：npm / CDN 分离验收

日期：2026-11-18。基线提交：`960c404`。本批为其后的本地未提交改动，未正式发布。版本、依赖和 tarball SHA256 见 [产物记录](./package-artifacts.json)；不能将当前本地 `0.3.2` 测试包当作 registry 已发布的 `0.3.2`。

浏览器服务直接读取 tarball 安装目录和该消费者的 Vite 生产产物。CDN URL 为本地 `/npm/@aiyazone/design-system@0.3.2/dist/cdn/index.js`，只请求一个 JS 文件，没有 import map、源码别名或远端模块替换。记录的最终包 JS/CSS 与浏览器已验收的产物逐文件 SHA256 完全一致。

这验证了固定版本路径对应的待发布文件，**不等同于 jsDelivr/unpkg 新版在线验收**。公开 registry 最新总包为旧 `0.3.2`；core/icons/i18n/utils 公开查询均返回 404。新入口正式发布后的 registry 安装与两家 CDN 核查，留在 ROADMAP 的 ZDS-01/ZDS-02 未完成项中。

现有主题会请求 Shopify CDN 上的 Poppins 字体。JavaScript 自包含不表示主题完全离线；浏览器结果保留了字体请求。直接 Node CJS 使用需要支持 `require(ESM)` 的 Node 和 DOM 环境，本次使用 Node 24；CI 使用 Node 22，Node 18 的纯 `require` 不在支持路径中。

机器可读 API/llms 使用正确的 npm 安装、JS/CSS 导入方式。首页及账户样例保留已发布 `0.3.2` 的旧 CDN 入口；正式发布新版后再同步切换。接入和旧版 JS/CSS 同步回退方法见 README §5.2，发布范围选项见 ROADMAP ZDS-02。

复验：

```bash
pnpm build
pnpm design:build
pnpm packages:check
pnpm packages:check:lit
pnpm packages:test:internal
# ZDS-02 起 packages:test 默认只测两公开包，复验本节六包需用 internal 命令。
# 上条命令打印“独立消费者”的临时目录；下条传入该路径。
# 环境：Python Playwright + Google Chrome。
python3 output/packages-20261118/check-browser.py <独立消费者目录>
```

浏览器检查自动关闭浏览器与 HTTP 服务。本批已在保存日志和产物 hash 后清理明确创建的三个消费者临时目录；复验时重新运行 `packages:test`。ZDS-06 再将安装、浏览器及临时目录清理接入 CI。
